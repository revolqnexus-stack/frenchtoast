## 🛠️ Maintenance & Updates

### How to Update Content

#### Add New Menu Item
Edit `public/assets/data/menu.js`:
```javascript
{
  name: 'New Dish Name',
  price: 450,
  description: 'Description here',
  category: 'French Toast'
}
```

#### Update Hours
Edit `config/business.ts`:
```typescript
hours: {
  weekday: { open: '9:00 AM', close: '10:00 PM' },
  weekend: { open: '8:00 AM', close: '10:00 PM' },
}
```

#### Add New Location
Edit `config/business.ts`, add to `locations` array.

#### Change Photos
Replace files in `/public/images/`  
Keep same filenames or update references in components.

### Need Help?
- Documentation in `SEO_SETUP_GUIDE.md`
- Image guide in `IMAGE_OPTIMIZATION.md`
- Contact developer for major changes
